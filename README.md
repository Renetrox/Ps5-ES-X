## Colecciones y carátulas de respaldo

Los metadatos por sistema son opcionales para que las colecciones sin descripción
conserven el diseño. El carrusel de sistemas utiliza `_default_sys.png` cuando
falta una carátula. Los logos pequeños conservan sus imágenes de respaldo sin
nombres superpuestos; los carruseles de juegos mantienen su configuración original.
Las animaciones y videos del más jugado se conservan.

Los layouts seleccionables siguen siendo Batman y Particles. Después de actualizar,
vuelve a aplicar tu layout para copiar su plantilla al XML activo.
