## Colecciones y tarjetas sin carátula

Batman y Particles, el XML activo y las plantillas históricas cargan los metadatos
por sistema de forma opcional. Las colecciones sin descripción propia conservan
el diseño. El carrusel de sistemas utiliza `_default_sys.png` y muestra el nombre
cuando falta una carátula. Los carruseles reales de juegos muestran el nombre
solo sobre la imagen de respaldo, con fuente SSTLight a 0.022 y dos líneas.
Las carátulas reales, animaciones y videos del más jugado se conservan.

Los layouts seleccionables siguen siendo Batman y Particles; las carpetas
`carousel gamelist` y `fake carousel` no se añaden al selector. Después de actualizar,
vuelve a aplicar tu layout para copiar su plantilla al XML activo.
